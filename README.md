# Candidrivo

An AI career assistant built with Python, Streamlit, and Google Gemini.

Current features:
- Upload and extract text from PDF and DOCX resumes.
- Extract an editable profile using Gemini.
- Review and confirm profile details and job preferences.
- Export and import JSON profile backups.

Initial measurement:
One profile extraction completed in 10 seconds using 4,279 total tokens.
This represents one test.

Planned features:
Job analysis, learning recommendations, tailored resumes and cover letters,
application tracking, and supported application automation.
